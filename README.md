# Резюме: Рубцов Валентин

Статический сайт-резюме (HTML, CSS, JS без сборки). Чёрно-красно-бело-серая гамма, анимации при прокрутке.

## Как выложить на GitHub Pages

1. Создай публичный репозиторий с именем `valaranje.github.io` (имя пользователя + `.github.io`).
2. Загрузи в корень репозитория всё содержимое этой папки: `index.html`, `resume.pdf`, `favicon.svg`, `.nojekyll`, папку `assets`.
3. Открой Settings, затем Pages. В Source выбери Deploy from a branch, ветка `main`, папка `/ (root)`, нажми Save.
4. Через 1–2 минуты страница откроется по адресу https://valaranje.github.io

## Что где менять

- Тексты, проекты, хакатоны: `index.html`
- Цвета (красный акцент, фоны): переменные в начале `assets/css/style.css`
- Фото: `assets/img/photo.jpg` (квадрат, лучше от 700 px)
- PDF-резюме для кнопки скачивания: `resume.pdf`

## Заметки

- Шрифт Manrope подключается с Google Fonts. Если он недоступен посетителю, страница использует системный шрифт.
- На странице нет телефона и даты рождения: контакты только email и Telegram.
